# Code of Conduct

## Our Standard

We want this project to be a welcoming, respectful place for everyone. Contributors and maintainers are expected to communicate constructively, accept feedback gracefully, and focus on what is best for the project and its users.

Examples of welcome behavior include:

- Showing empathy and respect for different experiences and viewpoints
- Giving actionable, technical feedback without personal attacks
- Taking responsibility for mistakes and helping repair their impact
- Respecting privacy and avoiding the publication of personal information

Harassment, discrimination, threats, insults, sexualized behavior, and deliberate disruption are not acceptable.

## Enforcement

Report unacceptable behavior privately through the maintainer's GitHub profile. Do not open a public issue containing sensitive information. Maintainers may edit or remove contributions and may temporarily or permanently restrict participation when behavior violates this standard.

This code applies in all project spaces and whenever someone publicly represents the project.
